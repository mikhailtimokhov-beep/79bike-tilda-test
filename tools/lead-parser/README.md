# Парсер лидов (дилеры / партнёры)

Ищет в городах мотосалоны, веломагазины, мотосервисы, прокаты — потенциальных дилеров электромотоциклов —
и собирает CSV: телефон, e-mail, Telegram/WhatsApp/VK, сайт, рейтинг, скоринг 0–100.

## Установка
```bash
pip install curl_cffi playwright
python -m playwright install chromium   # на своём ПК; не нужно, если запускать с --no-js
```

## Запуск
```bash
# Бесплатно, без ключей (OpenStreetMap):
python3 leads.py --cities "Казань,Самара,Уфа" --out leads.csv

# Больше и полнее (официальный API 2GIS, ключ на dev.2gis.com, есть бесплатный демо-ключ):
TWOGIS_KEY=ваш_ключ python3 leads.py --source all --query "мотосалон" --cities "Казань,Самара"

# Только «горячие»:
python3 leads.py --cities Казань --min-score 50
```

## Скоринг
телефон +30, e-mail +20, мессенджер +10, сайт +10, слово «электро» на сайте/в названии +25,
профильные слова (мото, питбайк, эндуро, квадро, скутер, дилер, сервис…) +5 каждое, максимум 100.

## Ограничения (честно)
- OSM в РФ покрывает примерно треть–половину точек, и контакты там заполнены не везде — основной объём даст 2GIS API.
- Яндекс.Карты и сайт 2GIS без API не парсим: это нарушает их условия, и с серверных IP они отдают блокировку.
- Холодная рассылка по e-mail юрлицам допустима, но по 38-ФЗ «О рекламе» нужна возможность отписки; звонки — без автодозвона.
