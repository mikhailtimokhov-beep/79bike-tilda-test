# Juliette's jewelry — автоматизация маркетинга, сайта, репутации и сервиса

Проект ведётся агентами Claude Code под контролем владельца и команды (`team.md`).
Временно лежит в папке `juliettes/` репозитория 79bike, в ветке `claude/juliettes-automation-strategy-9lpnbc`.
Когда будет создан отдельный репозиторий, содержимое папки станет его корнем, и агенты из `.claude/agents/` подключатся автоматически.

| Файл / папка | Что внутри |
|---|---|
| `00-strategiya-i-plan.md` | Стратегия, структура агентов, карта автоматизации, дорожная карта |
| `team.md` | Решения владельца, команда, зоны ответственности, недельный ритм |
| `.claude/agents/` | Агенты, созданные на сегодня: координатор, технический SEO-специалист, комплаенс, контент-стратег. Остальные — по мере начала фаз |
| `tasks/` | Задачи с исполнителем, инструкцией и критерием готовности |
| `campaigns/den-materi-2026/` | План кампании и недельные блоки на согласование |
| `scripts/check-site.mjs` | Автоматическая проверка сайта по открытым задачам (`node scripts/check-site.mjs`) |
