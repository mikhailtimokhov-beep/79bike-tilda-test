# Реестр агентов

Ведёт только агент-интегратор (`agent-registrar`). Вносится только то, что одобрил контроль качества (`quality-control`).

## Цепочка прохождения материалов
```
автор (агент) → compliance → quality-control ──┬─→ координатор → владелец (недельный блок + визуал)
                                               └─→ agent-registrar (только определения агентов)
```
