# Команда и решения владельца

## Решения владельца (04.11.2026)
| Тема | Решение |
|---|---|
| Согласование | **Блоком на неделю.** В пятницу координатор присылает блок на следующую неделю. Публикуется только то, что согласовано |
| Instagram | Работаем. На сайте и во всех материалах вне Instagram ставим пометку о Meta (SITE-002) |
| Клиенты и дети | Показывать можно, согласия есть. Перед каждой публикацией сверяемся с реестром согласий |
| Закрытые страницы | Открыть сразу (SEO-001) |
| День матери 29.11.2026 | Кампанию делаем (`campaigns/den-materi-2026/`) |
| Репозиторий | Отдельный для проекта |
| Визуализация | **Каждое согласование сопровождается визуалом**, если там есть что показать |
| Агенты | Вносит и проверяет только `agent-registrar`, и только после одобрения `quality-control` |
| Сотрудники | Помощь по сотрудникам пока не нужна. Агенты не ставят задачи сотрудникам, все вопросы адресуются владельцу. Владелец сообщит, когда подключать людей |
| Перечёркнутые цены | Не трогаем |
| Отзыв с неверной датой | Исправить (SITE-004) |

| **Бухгалтер** | Финансы | Координатор | Бюджеты на сервисы, оплата подписок, проверка цен и акций с точки зрения учёта |

## Ритм
- **Пн:** публикации согласованного блока начинают выходить по расписанию.
- **Ежедневно:** сводка по отзывам. Отзывы с оценкой 1–3 сразу уходят Любе и Юле.
- **Чт:** Борис передаёт цифры, координатор собирает отчёт.
- **Пт:** блок на следующую неделю уходит на согласование владельцу, через Любу.
